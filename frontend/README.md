# TaskFlow frontend

Aplicación React para gestión de proyectos y tareas, integrada con la API proporcionada.

Las instrucciones completas de instalación, configuración de PostgreSQL/API, ejecución y pruebas están en [README.md](../README.md) y [GUIA_PRUEBAS.md](../GUIA_PRUEBAS.md).

Configuración frontend: copia `.env.example` a `.env`, comprueba `VITE_API_URL` y ejecuta:

```bash
npm install
npm run dev
```
